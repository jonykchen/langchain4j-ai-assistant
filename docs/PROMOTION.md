## 详细介绍 (微博/知乎)

【开源推荐】LangChain4j AI Assistant - 企业级 AI 助手平台

🚀 项目简介
一个基于 LangChain4j 的生产级 AI 助手平台，支持多模型负载均衡、自动故障转移、完整可观测性链路。

✨ 核心特性
• 多模型负载均衡 - 权重分配 + 优先级故障转移
• 流式响应 - SSE 实时输出，思考过程可视化
• Agent 系统 - Function Calling、RAG 检索、Planning Agent
• 高可用架构 - 熔断、限流、重试、分布式限流
• 完整可观测性 - Prometheus + Grafana + Zipkin

🛠️ 技术栈
• 后端: Java 17, Spring Boot 3.4, LangChain4j 1.13
• 前端: Vue 3, Vite, Element Plus, TypeScript
• 数据库: PostgreSQL 16 + pgvector, Redis 7
• 可观测性: Prometheus, Grafana, Zipkin

📦 部署方式
支持 Docker Compose 一键部署，5 分钟启动完整服务。

🔗 项目地址
https://github.com/jonykchen/langchain4j-ai-assistant

## 英文介绍 (Reddit/Hacker News)

🤖 Just open-sourced my AI Assistant project!

**LangChain4j AI Assistant** - A production-ready AI assistant platform with multi-model load balancing and observability.

**Features:**
- 🔄 Multi-model load balancing with automatic failover
- 📡 SSE streaming response with thinking process visualization
- 🛠️ Function Calling + RAG + Planning Agent
- 📊 Complete observability (tracing, prompt management, evaluation)
- 🛡️ High availability (circuit breaker, rate limiting, retry)

**Tech Stack:**
- Backend: Java 17, Spring Boot 3.4, LangChain4j 1.13
- Frontend: Vue 3, Vite, Element Plus
- Database: PostgreSQL 16 + pgvector, Redis 7
- Observability: Prometheus, Grafana, Zipkin

**Quick Start:**
```bash
git clone https://github.com/jonykchen/langchain4j-ai-assistant
cd langchain4j-ai-assistant
make docker-up && make run
```
