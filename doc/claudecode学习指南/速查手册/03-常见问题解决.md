# 03 - 常见问题解决

> 快速查阅常见问题的解决方案。

## 安装与启动问题

### Q: 命令找不到 claude

**原因：** Claude Code 未添加到 PATH

**解决：**
```bash
# macOS / Linux
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 或重新安装
curl -fsSL https://claude.ai/install.sh | sh
```

### Q: API Key 无效

**原因：** 未设置环境变量或 Key 过期

**解决：**
```bash
# 设置环境变量
export ANTHROPIC_API_KEY=your-key-here

# 或在 ~/.claude/settings.json 中配置
```

### Q: 网络连接失败

**原因：** 网络问题或代理配置

**解决：**
```bash
# 设置代理
export HTTP_PROXY=http://proxy:port
export HTTPS_PROXY=http://proxy:port

# 或使用 VPN
```

## 文件操作问题

### Q: Claude 修改了错误的文件

**原因：** 描述不够精确

**解决：**
```markdown
明确指定文件路径和具体位置：

不是这个文件，我要改的是：
- 文件：src/service/UserService.java
- 方法：findById
- 行号：第 25 行
```

### Q: Claude 找不到文件

**原因：** 文件路径不对或文件不存在

**解决：**
```markdown
1. 确认文件存在：ls src/path/to/file
2. 使用相对路径：src/main/java/.../File.java
3. 让 Claude 搜索：查找所有 *Service.java 文件
```

### Q: 编辑失败，找不到匹配内容

**原因：** 内容已被修改或有隐藏字符

**解决：**
```markdown
让 Claude 重新读取文件：
读取 [文件路径]

然后指定更精确的上下文
```

## 权限问题

### Q: 每次操作都要确认

**解决：**
```json
// ~/.claude/settings.json
{
  "permissions": {
    "allow": [
      "Read(**)",
      "Write(src/**)",
      "Bash(npm:*)",
      "Bash(mvn:*)"
    ]
  }
}
```

### Q: 操作被拒绝

**原因：** 在黑名单中或不在白名单中

**解决：**
```markdown
检查 settings.json 的 permissions 配置：
- 移除 deny 中的相关规则
- 添加到 allow 列表
```

## 任务执行问题

### Q: Claude 理解错误

**解决：**
```markdown
提供更多上下文：

【背景】项目使用 Spring Boot + MyBatis-Plus
【目标】优化查询性能
【位置】src/repository/UserRepository.java
【参考】类似实现在 OrderRepository
```

### Q: 任务太复杂，Claude 卡住

**解决：**
```markdown
拆分成小步骤：

Step 1: 先做数据库设计
→ 确认后继续

Step 2: 再做实体类
→ 确认后继续

Step 3: 然后做 Service
```

### Q: 结果不符合预期

**解决：**
```markdown
提供示例：

期望效果：
```java
// 像这样
public Optional<User> findById(Long id) {
    return Optional.ofNullable(userMapper.selectById(id));
}
```

按这个格式重写。
```

## Git 问题

### Q: 提交失败

**原因：** pre-commit hook 失败或未配置用户信息

**解决：**
```bash
# 配置 git 用户信息
git config --global user.name "Your Name"
git config --global user.email "your@email.com"

# 检查 hook
ls .git/hooks/
```

### Q: PR 创建失败

**原因：** 未安装 gh 命令或未登录

**解决：**
```bash
# 安装 gh
brew install gh

# 登录
gh auth login
```

## 记忆问题

### Q: Claude 忘记了之前的约定

**解决：**
```markdown
1. 写入 CLAUDE.md
2. 保存到记忆：记住这个约定：...
3. 新会话开始时重申
```

### Q: 记忆文件太大

**解决：**
```markdown
# MEMORY.md 只保留索引
# 详细内容拆分到其他文件

memory/
├── MEMORY.md        # 索引（保持在 200 行内）
├── patterns.md      # 详细模式
└── debugging.md     # 详细经验
```

## 性能问题

### Q: 响应很慢

**原因：** 上下文太长或任务复杂

**解决：**
```markdown
1. 清空对话：/clear
2. 压缩历史：/compact
3. 指定具体文件，减少搜索
4. 使用更快模型：/model haiku
```

### Q: 上下文不够用

**解决：**
```markdown
1. 把关键信息写入 CLAUDE.md 和记忆
2. 定期 /clear 开始新对话
3. 使用 /compact 压缩历史
```
