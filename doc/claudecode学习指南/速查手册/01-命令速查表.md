# 01 - 命令速查表

> 快速查阅 Claude Code 的所有命令和快捷键。

## 启动命令

```bash
claude                              # 交互模式
claude "任务描述"                    # 单次执行
claude --resume                     # 恢复上次会话
claude --model claude-opus-4-6     # 指定 Opus 模型
claude --model claude-sonnet-4-6   # 指定 Sonnet 模型
claude --dangerously-skip-permissions  # 自动模式（慎用）
```

## 斜杠命令

### 对话管理

| 命令 | 作用 |
|------|------|
| `/help` | 显示帮助 |
| `/clear` | 清空对话历史 |
| `/compact` | 压缩对话历史 |
| `/model` | 切换模型 |

### 配置管理

| 命令 | 作用 |
|------|------|
| `/config` | 打开配置 |
| `/permissions` | 管理权限 |
| `/terminal-setup` | 终端设置 |

### 项目管理

| 命令 | 作用 |
|------|------|
| `/init` | 初始化 CLAUDE.md |
| `/memory` | 管理记忆 |
| `/mcp` | MCP 服务器管理 |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 中断操作 |
| `Ctrl + D` | 退出 |
| `Ctrl + L` | 清屏 |
| `↑` | 上一条历史 |
| `↓` | 下一条历史 |
| `Esc` | Vim 模式 |

## 权限配置

```json
// settings.json 结构
{
  "permissions": {
    "allow": ["Read(**)", "Write(src/**)", "Bash(npm:*)"],
    "deny": ["Bash(rm -rf:*)", "Write(.env)"]
  }
}
```

## 环境变量

```bash
# 设置环境变量
export ANTHROPIC_API_KEY=your-key

# 在 settings.json 中配置
{
  "env": {
    "NODE_ENV": "development"
  }
}
```
