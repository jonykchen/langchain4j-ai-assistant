# 02 - 场景速查表

> 按场景快速查阅常用任务描述模板。

## 功能开发

### 新增功能

```markdown
实现 [功能名称]：
- 功能点 1
- 功能点 2
- 功能点 3

参考：[已有类似代码路径]
约束：[限制条件]
```

### 添加接口

```markdown
在 [Controller] 中添加 [接口名称] 接口：
- 请求方式：GET/POST
- 请求参数：[参数列表]
- 返回格式：[响应结构]
- 业务逻辑：[描述]
```

### 添加页面

```markdown
添加 [页面名称] 页面：
- 路由：[/path]
- 组件：[组件结构]
- 功能：[功能列表]
- 调用接口：[API 列表]
```

## Bug 修复

```markdown
- 预期：[正确行为]
```

### 性能问题

```markdown

- 当前问题：[描述现状]

```

## 代码重构

### 拆分类

```markdown
重构 [类名]，拆分职责：
- 当前问题：类太长/职责不清
- 拆分方案：拆成 A、B、C 三个类
- 保持接口：保持原有 public 方法
```

### 优化代码

```markdown
优化 [文件/方法]：
- 当前问题：[描述问题]
- 优化方向：[期望改进]
- 约束：[保持兼容/不改接口]
```

## 代码审查

### 安全审查

```markdown
审查 [目录/文件] 的安全性：
- 检查：SQL 注入、XSS、权限绕过
- 输出：按严重程度排序，给出具体位置
```

### 性能审查

```markdown
审查 [目录/文件] 的性能问题：
- 关注：N+1 查询、大对象、循环调用
- 输出：问题列表 + 优化建议
```

### 规范审查

```markdown
审查 [目录/文件] 的代码规范：
- 参考：阿里巴巴 Java 开发手册
- 输出：违规列表 + 修改建议
```

## 测试相关
