# 01 - 工作原理深度解析

> 理解 Claude Code 的工作机制，更好地与 AI 协作。

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户终端                                │
│                    (你的命令行)                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   Claude Code CLI                            │
│                                                              │
│   ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │
│   │   工具层     │  │   上下文层   │  │   记忆层     │     │
│   │              │  │              │  │              │     │
│   │ • Read       │  │ • Git 状态   │  │ • CLAUDE.md  │     │
│   │ • Write      │  │ • 文件结构   │  │ • 记忆文件   │     │
│   │ • Edit       │  │ • 对话历史   │  │ • 自动记忆   │     │
│   │ • Bash       │  │ • 读取记录   │  │              │     │
│   │ • Glob/Grep  │  │              │  │              │     │
│   │ • Agent      │  │              │  │              │     │
│   └──────────────┘  └──────────────┘  └──────────────┘     │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  Claude API (Opus 4.6)                       │
│                                                              │
│              大语言模型 - 理解、规划、执行                    │
└─────────────────────────────────────────────────────────────┘
```

## 处理流程

当你输入一个请求时，Claude Code 的处理流程：

```
用户输入
    │
    ▼
┌─────────────┐
│ 意图理解    │  理解你想做什么
└─────────────┘
    │
    ▼
┌─────────────┐
│ 信息收集    │  调用工具获取需要的上下文
└─────────────┘
    │
    ▼
┌─────────────┐
│ 方案规划    │  制定执行计划
└─────────────┘
    │
    ▼
┌─────────────┐
│ 执行操作    │  调用工具完成任务
└─────────────┘
    │
    ▼
┌─────────────┐
│ 验证结果    │  确认任务完成
└─────────────┘
    │
    ▼
返回结果给用户
```

## 工具系统详解

Claude Code 通过工具与系统交互，每个工具有特定用途：

### 文件操作工具

| 工具 | 用途 | 触发场景 |
|------|------|----------|
| Read | 读取文件内容 | "读取 UserService.java" |
| Write | 创建新文件 | "创建 Helper.java" |
| Edit | 编辑现有文件 | "把 public 改成 private" |
| Glob | 文件模式搜索 | "查找所有 *Test.java" |
| Grep | 内容搜索 | "搜索 @Transactional" |

### 系统交互工具

| 工具 | 用途 | 触发场景 |
|------|------|----------|
| Bash | 执行命令 | "运行测试" "启动服务" |
| Agent | 启动子代理 | 复杂研究任务 |

### 信息工具

| 工具 | 用途 | 触发场景 |
|------|------|----------|
| WebFetch | 获取网页内容 | "查看这个文档" |
| WebSearch | 网络搜索 | "搜索最新的 React 教程" |

## 上下文管理

### 上下文来源

Claude Code 自动收集以下上下文：

```yaml
启动时加载:
  项目信息:
    - Git 状态（分支、修改、提交）
    - 项目文件结构
    - CLAUDE.md 内容

  记忆系统:
    - ~/.claude/projects/<项目>/memory/*.md
    - MEMORY.md 自动加载前 200 行

  配置信息:
    - settings.json 权限配置
    - 环境变量

对话中累积:
  - 对话历史（用户消息 + 工具调用 + 结果）
  - 读取过的文件内容
  - 命令执行结果
```

### 上下文压缩

当对话历史过长时，Claude Code 会自动压缩：

```
原始对话 (100 条消息)
        │
        ▼
┌─────────────────┐
│   压缩算法      │
│                 │
│ • 保留关键决策  │
│ • 保留代码修改  │
│ • 合并相似内容  │
└─────────────────┘
        │
        ▼
压缩后对话 (30 条摘要)
```

**手动压缩：**
```
/compact
```

## 记忆系统详解

### 记忆文件位置

```
~/.claude/projects/<项目路径>/memory/
├── MEMORY.md        # 主记忆文件（自动加载）
├── patterns.md      # 代码模式总结
├── debugging.md     # 调试经验
└── preferences.md   # 用户偏好
```

### 记忆触发机制

**会触发记忆保存的表述：**

```
✅ "记住这个模式..."
✅ "以后遇到这种情况就这样处理"
✅ "记录一下这个解决方案"
✅ "保存这个经验"
```

**不会触发记忆：**

```
❌ "这个方法是做什么的？"
❌ "帮我查一下..."
❌ "分析这个代码..."
```

### 记忆最佳实践

```markdown
# MEMORY.md 示例

## 项目概况
电商后台管理系统，Spring Boot + Vue 3

## 技术约定
- 使用 MyBatis-Plus，所有 Mapper 继承 BaseMapper
- 统一响应格式：Result<T>
- JWT 认证，Token 存 Redis

## 踩坑记录
- Docker 启动前检查端口占用
- 阿里云镜像解决 Maven 依赖下载慢

## 详细记录
- [代码模式](patterns.md)
- [调试经验](debugging.md)
```

## Agent 子代理

### 什么是 Agent？

Agent 是 Claude Code 的子进程，可以独立执行任务：

```
主会话
  │
  ├── Agent 1: 分析认证模块
  │
  ├── Agent 2: 分析支付模块
  │
  └── Agent 3: 分析日志模块
        │
        ▼
  结果汇总回主会话
```

### Agent 类型

| 类型 | 用途 |
|------|------|
| general-purpose | 通用任务，搜索代码，多步骤任务 |
| Explore | 快速探索代码库 |
| Plan | 架构规划，设计实现方案 |
| claude-code-guide | Claude Code 使用指南 |

### 何时使用 Agent

```
✅ 使用 Agent：
- 探索代码库架构
- 多文件并行分析
- 独立的研究任务
- 需要深度搜索的问题

❌ 不使用 Agent：
- 已知具体文件路径
- 简单的代码修改
- 单文件操作
```

## 权限系统

### 权限模式

```yaml
默认模式:
  - 敏感操作需要确认
  - 文件读写需要确认
  - 命令执行需要确认

自动模式 (--dangerously-skip-permissions):
  - 所有操作自动执行
  - 适合自动化脚本
  - 需要谨慎使用
```

### 权限配置

```json
// settings.json
{
  "permissions": {
    "allow": [
      "Read(**)",           // 允许读取所有文件
      "Bash(npm run:*)",    // 允许 npm run 命令
      "Bash(mvn:*)"         // 允许 mvn 命令
    ],
    "deny": [
      "Bash(rm -rf:*)",     // 禁止 rm -rf
      "Write(.env)"         // 禁止写入 .env
    ]
  }
}
```

## 小结

理解 Claude Code 的工作原理：

1. **工具系统** - 文件操作、命令执行、搜索等
2. **上下文管理** - 启动加载 + 对话累积 + 自动压缩
3. **记忆系统** - 持久化保存重要信息
4. **Agent 子代理** - 并行处理独立任务
5. **权限系统** - 保护敏感操作
