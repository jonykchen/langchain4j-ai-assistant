# 02 - 高阶使用技巧

> 掌握高级技巧，成为 Claude Code 高手。

## 高效沟通模式

### 模式一：背景-目标-约束

```markdown
【背景】
我们有一个订单系统，用户反馈下单偶尔超时。

【目标】
优化下单接口性能，目标响应时间 < 500ms。

【约束】
- 不能更换数据库
- 必须保证事务一致性
- 周五前上线
```

**为什么有效：** Claude 知道起点、终点和边界，能给出更精准的方案。

### 模式二：示例驱动

```markdown
【当前代码】
```java
public List<User> findUsers(String name) {
    return userMapper.selectAll().stream()
        .filter(u -> u.getName().contains(name))
        .collect(Collectors.toList());
}
```

【期望效果】
改成数据库模糊查询，避免全表加载。

【参考】
类似实现见 OrderMapper#searchByKeyword
```

**为什么有效：** 具体的示例消除了歧义，Claude 能精确理解你的意图。

### 模式三：分步确认

```markdown
请帮我重构 PaymentService：

Step 1: 分析当前代码结构，列出问题清单
→ 等我确认后继续

Step 2: 设计新的类结构
→ 等我确认后继续

Step 3: 逐步实施重构
```

**为什么有效：** 复杂任务分步执行，每一步都可以验证和调整。

## Agent 并行处理

### 场景：并行分析多个模块

```
同时分析以下三个模块的安全性：

1. src/auth - 认证模块
2. src/api - 接口模块
3. src/websocket - 实时通信模块

每个模块输出独立的安全报告，包含：
- 潜在漏洞
- 风险等级
- 修复建议
```

Claude 会启动多个 Agent 并行工作，最后汇总结果。

### 场景：深度代码探索

```
分析这个项目的缓存策略，需要：
1. 找出所有使用 Redis 的地方
2. 分析缓存 key 的命名规范
3. 检查是否有缓存穿透风险
4. 给出优化建议
```

Claude 会使用 Explore 类型的 Agent 进行深度搜索。

## Git 工作流集成

### 智能提交

```
提交当前的积分功能改动，commit message 包含：
- 新增的功能点
- 修改的文件概要
```

Claude 会：
1. 查看当前 git 状态
2. 分析代码改动
3. 生成规范的 commit message
4. 执行 git add 和 git commit

### 创建 PR

```
为当前分支创建 PR：
- 标题：feat: 用户积分功能
- 目标分支：develop
- 包含功能说明和测试计划
```

### 代码审查

```
审查最近的 3 个提交，重点关注：
1. 代码质量
2. 安全漏洞
3. 性能问题
```

## Hooks 自动化

### 配置 Hooks

```json
// settings.json
{
  "hooks": {
    // 任务完成时播放提示音
    "stop": "afplay /System/Library/Sounds/Glass.aiff",

    // 开始处理时提示
    "user-prompt-submit": "echo '⏳ 处理中...'"
  }
}
```

### 条件 Hooks

```json
{
  "hooks": {
    "tool-use": [
      {
        "matcher": "Bash(rm:*)",
        "hooks": ["echo '⚠️ 即将执行删除操作'"]
      },
      {
        "matcher": "Write(**)",
        "hooks": ["echo '📝 正在写入文件'"]
      }
    ]
  }
}
```

## 自定义 Skills

### 创建 Skill

文件位置：`.claude/skills/review.md`

```markdown
---
name: review
description: 代码审查
---

## 审查步骤

1. 获取当前分支的改动文件
2. 逐个文件检查：
   - 代码规范
   - 安全漏洞
   - 性能问题
3. 输出审查报告

## 输出格式

### [文件名]
- [ ] 代码规范: [问题]
- [ ] 安全: [问题]
- [ ] 性能: [问题]
```

### 使用 Skill

```
/review
```

## 批量操作技巧

### 批量重命名

```
把 src/service 目录下所有 *ServiceImpl.java 重命名为 Default*Service.java
```

### 批量添加注解

```
给 src/controller 目录下所有 Controller 类添加 @Slf4j 注解
```

### 批量修改

```
把项目中所有 System.out.println 替换成 log.info
```

## 小结

高阶技巧要点：

1. **高效沟通** - 背景-目标-约束、示例驱动、分步确认
2. **Agent 并行** - 多模块同时分析，提高效率
3. **记忆系统** - 组织记忆文件，主动保存重要信息
4. **Git 集成** - 智能提交、PR 创建、代码审查
5. **调试排错** - 错误分析、日志诊断、性能优化
6. **Hooks 自动化** - 任务完成提醒、条件触发
7. **自定义 Skills** - 封装常用工作流
