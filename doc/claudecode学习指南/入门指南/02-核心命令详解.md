# 02 - 核心命令详解

> 掌握 Claude Code 的所有内置命令和快捷键。

## 斜杠命令

在对话中输入 `/` 开头的命令来执行特殊操作。

### 帮助与信息

| 命令 | 作用 | 示例 |
|------|------|------|
| `/help` | 显示帮助信息 | `/help` |
| `/model` | 切换模型 | `/model opus` |

### 对话管理

| 命令 | 作用 | 示例 |
|------|------|------|
| `/clear` | 清空对话历史 | `/clear` |
| `/compact` | 压缩对话历史 | `/compact` |

### 配置管理

| 命令 | 作用 | 示例 |
|------|------|------|
| `/config` | 打开配置设置 | `/config` |
| `/permissions` | 管理权限 | `/permissions` |

### 项目管理

| 命令 | 作用 | 示例 |
|------|------|------|
| `/init` | 初始化 CLAUDE.md | `/init` |
| `/memory` | 管理记忆 | `/memory` |

### 工具管理

| 命令 | 作用 | 示例 |
|------|------|------|
| `/mcp` | MCP 服务器管理 | `/mcp` |
| `/terminal-setup` | 终端集成设置 | `/terminal-setup` |

## 快捷键

### 通用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 中断当前操作 |
| `Ctrl + D` | 退出 Claude Code |
| `Ctrl + L` | 清屏 |

### 输入快捷键

| 快捷键 | 功能 |
|--------|------|
| `↑` | 上一条历史命令 |
| `↓` | 下一条历史命令 |
| `Enter` | 发送消息 |
| `Esc` | 进入 Vim 模式 |

### Vim 模式快捷键

按 `Esc` 进入 Vim 模式后：

| 快捷键 | 功能 |
|--------|------|
| `i` | 插入模式 |
| `:w` | 保存当前输入 |
| `:q` | 退出 Vim 模式 |
| `dd` | 删除当前行 |
| `yy` | 复制当前行 |
| `p` | 粘贴 |

## 命令行选项

启动 Claude Code 时可以添加参数：

```bash
# 常用选项
claude --help                    # 显示帮助
claude --version                 # 显示版本
claude --resume                  # 恢复上次会话

# 模型选择
claude --model claude-opus-4-6   # 使用 Opus 模型
claude --model claude-sonnet-4-6 # 使用 Sonnet 模型

# 权限模式
claude --dangerously-skip-permissions  # 跳过所有确认（慎用！）

# 输出模式
claude --output-format json      # JSON 格式输出
claude --quiet                   # 静默模式
```
