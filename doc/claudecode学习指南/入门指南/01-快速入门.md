# 01 - Claude Code 快速入门

> 本文档帮助你快速上手 Claude Code，了解基本概念和使用方式。

## 什么是 Claude Code？

Claude Code 是 Anthropic 官方推出的 AI 编程助手，直接在终端中运行。它能够：

- 理解你的整个代码仓库
- 执行复杂的编程任务
- 自动读取、编辑、创建文件
- 运行命令和测试
- 与 Git 工作流深度集成

## 安装与启动

### 安装

```bash
# macOS / Linux
curl -fsSL https://claude.ai/install.sh | sh

# 或通过 npm
npm install -g @anthropic-ai/claude-code
```

### 启动方式

```bash
# 交互式会话（推荐新手使用）
claude

# 直接执行单次任务
claude "修复登录页面的样式问题"

# 指定模型
claude --model claude-opus-4-6

# 恢复上次会话
claude --resume
```

## 第一次对话

启动后，你会看到 Claude Code 的提示符。试着输入：

```
帮我看看这个项目的结构
```

Claude Code 会：
1. 分析当前目录
2. 识别项目类型
3. 给出项目概览

## 基本交互方式

### 描述你的需求

用自然语言描述你想做什么：

```
# 好的描述
帮我优化 UserService 中的查询方法，目前有 N+1 问题

# 不够好的描述
优化代码
```

### 让 Claude 读取文件

```
读取 src/main/java/com/example/UserService.java
```

### 让 Claude 搜索代码

```
搜索所有使用了 @Transactional 注解的方法
```

### 让 Claude 修改代码

```
把 UserService 中的 findById 方法改成返回 Optional
```

## 权限确认

Claude Code 在执行敏感操作时会请求你的确认：

```
Claude 想要执行：Write(src/main/java/...)
允许吗？[y/n/always]
```

- `y` - 本次允许
- `n` - 拒绝
- `always` - 以后都允许这类操作

## 清空对话

当对话历史太长或想开始新任务时：

```
/clear
```
