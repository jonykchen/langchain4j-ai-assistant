## 核心要点速记

### 高效沟通三要素

1. **背景** - 项目情况、技术栈
2. **目标** - 想要达成什么
3. **约束** - 不能做什么、限制条件

### 三大工作模式

1. **TDD 模式** - 先写测试，再实现
2. **渐进重构** - 分步拆解，逐步优化
3. **代码审查** - 系统检查，输出报告

### 避免常见错误

1. ❌ 模糊描述 → ✅ 明确文件和行号
2. ❌ 一步到位 → ✅ 分步执行确认
3. ❌ 忽略测试 → ✅ 改动后验证
4. ❌ 过度信任 → ✅ 检查关键逻辑
